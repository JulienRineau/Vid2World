# =========================================================================
# TIPS FOR BEST RESULTS
# =========================================================================

# 1. Episode Selection for Cross-Swap:
#    - Choose episodes with DIFFERENT action patterns
#    - One with large hand movements, one with small/precise movements
#    - This makes the cross-swap effect more visually apparent

# 2. Guidance Scale:
#    - Default 2.5 is good for general quality
#    - Higher (3.0-4.0) increases action following but may reduce diversity
#    - Lower (1.5-2.0) more diverse but weaker action conditioning

# 3. DDIM Steps:
#    - 50 steps is good balance of quality/speed
#    - 100 steps for final blog post videos
#    - 25 steps for quick testing

# 4. Autoregressive vs Non-AR:
#    - AR (--ar flag) gives more coherent temporal dynamics
#    - Non-AR is faster but may have temporal artifacts
#    - Use AR for final blog post videos

# 5. Output FPS:
#    - 3-4 fps is typical for manipulation videos
#    - Matches the original data collection framerate
#    - Higher fps looks smoother but may seem "fast"
